# 🚀 AI 模型配置管理系统 - 快速启动指南

## 🎯 系统概述

这是一个完整的 AI 聊天系统，支持：
- ✅ 用户认证和会话管理
- ✅ 多模型动态配置
- ✅ 智能配额管理
- ✅ 流式对话响应
- ✅ 会话历史保存

## 📋 前置要求

- Python 3.10+ (conda环境: kimitalk)
- Node.js 16+
- SQLite 3

## 🛠️ 快速启动步骤

### 步骤 1: 配置后端

```bash
cd backend

# 1. 激活 conda 环境
conda activate kimitalk

# 2. 确认依赖已安装
pip install cryptography==41.0.7 openai==1.6.1

# 3. 配置环境变量
cp .env.example .env

# 编辑 .env 文件，添加加密密钥：
# ENCRYPTION_KEY=<生成的随机密钥>
```

**生成加密密钥**：
```python
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 步骤 2: 初始化数据库

```bash
# 数据库已迁移完成
# 如果需要重新迁移：
# alembic upgrade head
```

### 步骤 3: 启动后端服务

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**访问 API 文档**：http://localhost:8000/docs

### 步骤 4: 启动前端

```bash
# 打开新终端
cd frontend

# 安装依赖（如果未安装）
npm install

# 启动开发服务器
npm run dev
```

**访问前端**：http://localhost:5173

## 👤 首次使用流程

### 1. 注册账号

1. 访问 http://localhost:5173
2. 点击"注册"
3. 输入邮箱和密码
4. 注册成功后自动登录

### 2. 添加模型配置

1. 登录后，点击右上角头像
2. 选择"模型管理"
3. 点击"添加模型"
4. 填写表单：

**示例 - OpenAI GPT-4**：
```
模型名称: GPT-4
模型标识: gpt-4
API 地址: https://api.openai.com/v1
API Key: sk-your-openai-api-key
描述: OpenAI GPT-4 模型
配额限制: 1000000
```

**示例 - DeepSeek**：
```
模型名称: DeepSeek Chat
模型标识: deepseek-chat
API 地址: https://api.deepseek.com/v1
API Key: your-deepseek-api-key
描述: DeepSeek 聊天模型
配额限制: 5000000
```

**示例 - Kimi**：
```
模型名称: Kimi
模型标识: moonshot-v1-8k
API 地址: https://api.moonshot.cn/v1
API Key: your-kimi-api-key
描述: Moonshot Kimi 模型
配额限制: 1000000
```

5. 点击"保存"

### 3. 开始聊天

1. 回到主页
2. 在输入框上方选择模型
3. 输入消息并发送
4. 享受 AI 对话！

## 🐛 常见问题

### 1. 后端启动失败

**问题**: ImportError 或模块找不到

**解决**：
```bash
# 确认在正确的 conda 环境
conda activate kimitalk

# 重新安装依赖
pip install -r requirements.txt
```

### 2. 数据库迁移失败

**问题**: 表已存在

**解决**：
```bash
# 运行修复脚本
python fix_migration.py

# 然后运行迁移
alembic upgrade head
```

### 3. 前端无法连接后端

**问题**: Network Error 或 CORS 错误

**解决**：
- 确认后端已启动: http://localhost:8000/docs
- 检查 CORS 配置
- 清除浏览器缓存

### 4. 模型无法使用

**问题**: 429 错误或模型未显示

**解决**：
1. 检查模型是否激活 (`is_active = true`)
2. 检查配额是否用尽
3. 验证 API Key 是否正确
4. 在模型管理页面重置配额

### 5. API Key 解密失败

**问题**: "Failed to decrypt API key"

**解决**：
1. 检查 `ENCRYPTION_KEY` 是否设置
2. 不要更改已有的加密密钥
3. 如需更换密钥，需重新添加所有模型

## 🎯 进阶配置

### 配置多个模型

建议至少配置 2-3 个不同的模型作为备份：

1. **主力模型**：高性能模型（如 GPT-4）
2. **备用模型**：经济型模型（如 GPT-3.5）
3. **测试模型**：本地模型或免费模型

### 配额管理策略

1. **按需求设置配额**：
   - 个人使用：100万 tokens/月
   - 小团队：500万 tokens/月
   - 企业使用：自定义

2. **监控使用情况**：
   - 每周检查配额使用
   - 配额超过 80% 时及时充值
   - 记录高使用量对话

3. **优化使用成本**：
   - 日常任务用经济型模型
   - 复杂任务用高性能模型
   - 测试用本地模型

### 自动化重置（未来功能）

当前支持手动重置配额，后续版本将支持：
- Cron 表达式自动重置
- 每月/每周定时重置
- 配额用尽邮件通知

## 🔐 安全建议

### 生产环境部署

1. **更改所有密钥**：
```bash
# JWT 密钥
JWT_SECRET_KEY=<随机生成>

# 加密密钥
ENCRYPTION_KEY=<随机生成>
```

2. **使用 HTTPS**：
- 配置 SSL 证书
- 强制 HTTPS 重定向

3. **数据库安全**：
- 定期备份数据库
- 限制数据库访问权限
- 加密敏感数据

4. **API Key 管理**：
- 不要在代码中硬编码
- 使用环境变量
- 定期轮换密钥
