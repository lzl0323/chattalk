## 快速开始

### 首次访问

1. 打开浏览器访问应用地址
2. 你会看到登录页面
3. 点击"还没有账户？立即注册"

### 注册账户

1. 输入你的邮箱地址
2. 设置密码（至少 6 个字符）
3. 确认密码
4. 点击"注册"按钮

![注册界面](../assets/register.png)

### 登录

1. 输入注册时使用的邮箱
2. 输入密码
3. 点击"登录"按钮

登录成功后，系统会自动保存你的登录状态，下次访问无需重新登录。

## 用户认证

### 自动登录

系统使用 JWT Token 进行认证，Token 有效期为 7 天。在有效期内，你无需重复登录。

### 安全提示

- 使用强密码（建议包含字母、数字和特殊字符）
- 不要与他人分享你的账户
- 定期更改密码
- 使用完毕后建议退出登录

### 退出登录

点击侧边栏顶部的退出图标即可退出登录。

## 聊天功能

### 发起对话

1. 登录后自动进入主界面
2. 在底部输入框输入你的问题
3. 按回车或点击发送按钮

### 示例问题

首次进入时，你会看到一些示例问题，点击即可快速开始对话：
- 请介绍一下 Vue 3 的主要特性
- 如何优化网站性能？
- 请解释一下机器学习的基本概念
- 给我推荐一些学习编程的资源

### 实时响应

AI 的回复会以流式方式逐字显示，提供更自然的对话体验。

### 多轮对话

系统会自动维护对话上下文，你可以进行连续的多轮对话：

```
你：什么是 Vue.js？
AI：Vue.js 是一个用于构建用户界面的渐进式 JavaScript 框架...

你：它和 React 有什么区别？
AI：（AI 会基于之前关于 Vue.js 的讨论来回答）
```

### Markdown 支持

AI 回复支持 Markdown 格式，包括：
- **粗体**和 *斜体*
- 代码块
- 列表
- 链接

## 历史管理

### 侧边栏概览

左侧边栏显示你的所有对话历史，包括：
- 对话标题
- 消息数量
- 最后更新时间

### 新建对话

点击顶部的"新建对话"按钮创建新的对话。

### 切换对话

点击侧边栏中的任意对话项即可切换到该对话。

### 搜索对话

使用侧边栏顶部的搜索框搜索对话：
1. 输入关键词（搜索标题）
2. 系统会自动过滤显示匹配的对话

### 重命名对话

1. 将鼠标悬停在对话项上
2. 点击铅笔图标
3. 输入新的标题
4. 按回车或点击外部保存

### 删除对话

1. 将鼠标悬停在对话项上
2. 点击垃圾桶图标
3. 确认删除

⚠️ **注意**：删除对话将永久移除所有消息，无法恢复！

### 对话自动保存

每条消息都会自动保存到数据库，包括：
- 你发送的消息
- AI 的回复
- 时间戳

你无需手动保存，所有内容都会持久化存储。

## 功能特性

### ✨ 核心功能

- **用户认证**：安全的邮箱密码登录
- **对话管理**：创建、重命名、删除对话
- **历史记录**：自动保存所有对话
- **实时响应**：流式显示 AI 回复
- **搜索功能**：快速查找历史对话
- **响应式设计**：支持各种屏幕尺寸

### 🔒 隐私与安全

- 密码使用 bcrypt 加密存储
- JWT Token 安全认证
- 数据隔离（每个用户只能访问自己的数据）
- HTTPS 加密传输（生产环境）

### 📊 限制说明

- **消息长度**：单条消息最多 4000 字符
- **上下文限制**：每次对话最多保留最近 10 条消息
- **Token 有效期**：7 天（过期后需重新登录）

## 常见问题

### Q: 忘记密码怎么办？

A: 目前系统暂不支持密码重置功能，请联系管理员或使用另一个邮箱重新注册。

### Q: 可以导出对话记录吗？

A: 目前暂不支持导出功能，后续版本将添加此功能。

### Q: 为什么有时候 AI 回复不完整？

A: 可能是网络问题或服务器繁忙，请稍后重试。如果问题持续，请检查网络连接。

### Q: 多个设备可以同时登录吗？

A: 可以，但建议在同一时间只在一个设备上使用，以避免数据冲突。

### Q: 对话可以分享给其他人吗？

A: 目前暂不支持分享功能，所有对话都是私密的。

### Q: 系统支持哪些浏览器？

A: 推荐使用最新版本的：
- Chrome / Edge（Chromium）
- Firefox
- Safari

### Q: 移动端可以使用吗？

A: 可以，系统采用响应式设计，支持手机和平板访问。

### Q: AI 回复的内容可以编辑吗？

A: 不可以直接编辑，但你可以重新发送问题获得新的回复。

### Q: 如何清空所有对话？

A: 需要逐个删除对话，或联系管理员清空数据库。

### Q: Token 过期后会发生什么？

A: 系统会自动跳转到登录页面，重新登录即可。

## 技巧与建议

### 💡 获得更好回复的技巧

1. **明确问题**：清楚地描述你的问题
2. **提供上下文**：给出足够的背景信息
3. **分步提问**：复杂问题拆分成多个简单问题
4. **具体示例**：提供具体的例子或场景

### 📝 对话管理建议

1. **及时重命名**：给对话起一个有意义的标题
2. **定期清理**：删除不再需要的对话
3. **主题分类**：为不同主题创建独立对话
4. **关键对话标记**：重要对话可以在标题前加标记如 ⭐
