# 重启前端服务器

## 问题
汉堡菜单按钮没有显示

## 解决方案

### 步骤 1：停止前端服务器
在运行前端的终端窗口按 `Ctrl + C` 停止服务器

### 步骤 2：重新启动
```bash
cd e:\PROJECT-lzl\chattalk\frontend
npm run dev
```

### 步骤 3：清除浏览器缓存
在浏览器按 `Ctrl + Shift + R` 强制刷新

## 检查点
刷新后，在聊天页面顶部应该能看到：

```
☰  对话标题                    模型选择器
```

左侧的 ☰ 图标就是汉堡菜单按钮。

## 如果还是看不到
请打开浏览器开发者工具（F12），查看 Console 标签页，看是否有错误信息。
